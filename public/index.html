Preguntas frecuentes

Uso del portal

¿Cómo puedo solicitar soporte?

Selecciona el servicio que necesitas y completa el formulario de solicitud con los datos de tu incidencia.

¿Qué información debo colocar en la solicitud?

Describe brevemente el problema, indica el tipo de incidencia y selecciona el nivel de prioridad correspondiente.

¿Puedo solicitar ayuda desde mi celular?

Sí. El portal está diseñado para facilitar la consulta y el registro de una solicitud desde dispositivos móviles.

Atención y soporte

¿Qué ocurre después de completar el formulario?

En esta práctica el formulario solo valida los datos ingresados. No se envían ni se almacenan tickets reales.

¿Qué prioridad debo seleccionar?

Selecciona alta, media o baja según el impacto que tenga la incidencia en tus actividades.
